Exécuter la commande de lancement dev définie dans la section **Commandes de développement** de l'archi active dans `docs/agent/archis/`.

Procédure :
1. Identifier l'archi active depuis `docs/agent/project-context.md §Stack` (ou le seul fichier présent dans `docs/agent/archis/`).
2. Lire la section `## Commandes de développement` du fichier d'archi.
3. Exécuter la commande de dev principale (bloc `# Dev`).

Si aucune archi n'est présente ou si la commande n'est pas documentée : le signaler, ne pas deviner.
